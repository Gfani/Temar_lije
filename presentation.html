Real-Time Chat & Voice Architecture

Built with NestJS WebSockets (`@nestjs/websockets`) and PostgreSQL persistence.

🚀 Capabilities
  • Zero-Lag Messaging: Real-time room broadcast via `newMessage` events.
  • Built-in Voice Notes: Browser `MediaRecorder` audio capture with streaming media headers.
  • Live Presence: Online indicator green dots and typing feedback.
  • Telegram-Style Topics: Threaded subchannels within study groups.
// NestJS ChatGateway (chat.gateway.ts) @SubscribeMessage('sendMessage') async handleMessage(@ConnectedSocket() client, @MessageBody() data) { await this.chatService.validateAccess(client.user.id, data.groupId); const msg = await this.chatService.saveMessage(data); this.server.to(`room_${data.groupId}`).emit('newMessage', msg); }

Data Privacy & Role-Based Access Control

Enforcing confidential peer study groups and teacher administrative control.

🔒 Student Privacy
Non-members cannot discover or query private study groups. DB queries strictly enforce `members: { some: { userId } }`.
🚫 Teacher Isolation
Teachers are explicitly excluded from student peer study groups to ensure confidentiality during peer discussions.
👑 Teacher Authority
Teachers can remove students (revoking accounts) and delete classrooms with full database cascade cleanup.

DevOps & Azure Cloud Infrastructure

Production multi-container orchestration with Docker Compose.

🐘 temar_db
PostgreSQL 16 Alpine container with named volume persistence (`pgdata`) and automated schema seeding.
⚡ temar_backend
Node.js 20 Alpine running NestJS production API & Socket.io server on port 3000.
🌐 temar_frontend
Multi-stage Vite build served through high-performance Nginx Alpine on Ports 80 and 443.

Nginx Reverse Proxy & SSL Encryption

End-to-end HTTPS/TLS with automated Let's Encrypt certificates.

# Production Nginx Reverse Proxy (temar_lije/nginx.conf) server { listen 443 ssl; server_name temar-lije.southafricanorth.cloudapp.azure.com temarlije.mooo.com; location / { try_files $uri $uri/ /index.html; } # SPA Frontend location /api/ { proxy_pass http://backend:3000/; } # REST Endpoints location /socket.io/{ proxy_pass http://backend:3000; # Real-time WebSockets proxy_set_header Upgrade $http_upgrade; proxy_read_timeout 86400s; } }
